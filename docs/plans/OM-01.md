# OM-01 Monorepo Bootstrap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A fresh clone on either machine runs `make bootstrap && make up PROFILES="core"` to a healthy Postgres/Redis/OPA stack in < 2 min, with a Gradle multi-project, Compose profiles, DB roles that enforce truth isolation, and CI jobs that always report.

**Architecture:** Gradle Kotlin DSL root with three subprojects (two skeleton Spring Boot apps + a java-library for generated contracts). One `infra/compose/docker-compose.yml` with six profiles; `make up` uses `docker compose up --wait` so "healthy" is the exit code. CI path filtering happens *inside* the workflow (a `changes` job + job-level `if:`), never on the trigger, so required checks always report.

**Tech Stack:** Java 21 (Temurin), Spring Boot 3.5.16, Gradle 8.14.6 wrapper, Docker Compose v2, Postgres 17, Redis 7, OPA 1.x, Kafka 4 (KRaft), OTel/Jaeger/Prometheus/Grafana, Toxiproxy, pre-commit (gitleaks, LF, EOF), GitHub Actions; stdlib Python for scripts/tests.

**Spec:** card OM-01 (`python3 scripts/board.py show OM-01`), §7 (stack, "only ledger mutates; only grader sees oracle labels"), §9 (oracle tables isolated), §19 CI design, NFR-06, NFR-11, ADR-009, ADR-010, RSK-12, `infra/CLAUDE.md`, `docs/setup/GITHUB.md` (OM-25). The spec pins no versions, roles, startup or memory budgets; those below come from the card, CLAUDE.md and upstream registries checked 2026-10-28.

**Starts after:** #6 (SH-01) and #7 (OM-25) are merged — the board dep, and Task 1 extends OM-25's guards. Rebase this branch on main first.

## Decisions (Om to confirm at plan review)

| # | decision | why |
|---|---|---|
| D1 | Path filtering = `changes` job (stdlib `scripts/ci_changes.py`) + `if: needs.changes.outputs.<x> == 'true'` on each job; triggers unfiltered | A trigger-filtered workflow never reports → a required check blocks docs-only PRs forever. A job skipped by `if:` reports *skipped*, which satisfies a required check. No third-party paths action (ADR-010). |
| D2 | OM-01 ships CI jobs `lint`, `java`, `stack`; `python` is KG-01's, `policy` lands with the first Rego card, `console` with OM-21 | Each job needs code to test; an empty job is a fake green (§19 "No CI claim without execution logs"). The `changes` job makes each later job ~10 lines. |
| D3 | Gradle 8.14.6, not 9.x | Spring Boot 3.5's supported Gradle range is the safe pin; 9.x only via a later bump. |
| D4 | DB: NOLOGIN group roles `ledger_app`, `grader_ro`, `operator`; login users `ledger_svc`, `grader_svc`, `operator_svc` from `.env` (generated by bootstrap, gitignored). Schemas `ledger` (owner `ledger_app`), `audit`, `eval` (owner `postgres` until KG cards add a writer) | Golden rule 4: truth (eval) never reaches ledger or console → `ledger_app` and `operator` get nothing on `eval`. Audit is append-only from the ledger → INSERT+SELECT only, and the ledger can't own audit tables. |
| D5 | `make reset` stays TODO(OM-04), `make codegen` stays TODO(SH-02) | Their cards own them (Makefile already says so). |
| D6 | `app` profile = ledger + gateway skeletons now; mcp-adapter joins in OM-06, supervisor (events) in KG cards, console (ui) in OM-21 | No service without code; profile names are fixed now so later cards only add entries. |

## Global Constraints

- Images pinned to exact multi-arch tags (amd64 + arm64 verified 2026-10-28), never `latest`: `postgres:17.11-alpine`, `redis:7.4.12-alpine`, `openpolicyagent/opa:1.21.4-static`, `apache/kafka:4.4.0`, `otel/opentelemetry-collector-contrib:0.164.0`, `jaegertracing/jaeger:2.22.0`, `prom/prometheus:v3.15.1`, `grafana/grafana:12.4.14`, `ghcr.io/shopify/toxiproxy:2.13.0`, `eclipse-temurin:21.0.12.1_1-{jdk,jre}-noble`.
- Every Compose service: `healthcheck`, `mem_limit`, at least one profile from {core, app, events, obs, ui, chaos}; host ports bound to `127.0.0.1`; secrets only as `${VAR:?}` from `.env`.
- Memory: core profile ≤ 768 MB total (postgres 512m, redis 128m, opa 128m); JVM services `-Xmx512m`, `mem_limit: 768m`. Om's WSL currently reports **5 GB** total (`free -g`), not the 10 GB in CLAUDE.local.md — check `.wslconfig` before running more than core+app.
- Gradle: `org.gradle.jvmargs=-Xmx512m`, `org.gradle.workers.max=4`, wrapper with `distributionSha256Sum`.
- No Kubernetes (ADR-009). No new framework without a test that needs it (ADR-010, RSK-12).
- Third-party GitHub actions pinned by commit SHA; `actions/*` by major tag (repo convention).
- Tests: Python stdlib `unittest`, files `tests/{kit,infra}/test_om_01_*.py`, names `test_OM_01_*`; JUnit names `OM01_*`.
- Branch `om/OM-01-bootstrap`; commits `OM-01 §7 §19: …` + Co-Authored-By line.

## Review Focus

1. **Docs-only PR after `java`/`stack` become required** → must merge (jobs report *skipped*). Pinned by `test_OM_01_required_jobs_always_report` (Task 1) and V3 in Task 6.
2. **`ledger_svc` reads truth** (`SELECT` on `eval.*`, or a table created later in `eval`) → permission denied. Pinned by `test_OM_01_ledger_cannot_read_eval` incl. a table created *after* init (default privileges) (Task 3).
3. **Postgres reachable from the LAN / coffee-shop Wi-Fi** → only `127.0.0.1` binds. Pinned by `test_OM_01_ports_loopback_only` (Task 4).
4. **Fresh clone with no `.env`** → bootstrap generates one with random passwords; `make up` without `.env` fails with a clear message, never with a default password. Pinned by `test_OM_01_bootstrap_env_*` (Task 3).
5. **A tampered Gradle wrapper jar / distribution** → wrapper verifies `distributionSha256Sum`; CI runs `gradle/actions/wrapper-validation`. Pinned by `test_OM_01_wrapper_pinned` (Task 2).
