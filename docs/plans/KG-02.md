# KG-02 Public reference-data snapshots — Implementation Plan

> **For agentic workers:** use superpowers:executing-plans; steps are checkboxes, test first.

**Goal:** frozen, hashed, licensed snapshots of the public reference data B4/B7/B8 need (ECB and Fed H.10 FX, a small GLEIF subset, ISO 20022 settlement status/reason codes) under `data/reference/<source>/<date>/`, one `data/reference/MANIFEST.json`, a re-hash check, and a factory loader that reads reference data **only** through that manifest.

**Spec:** card KG-02 · §6 (provenance, "information-only" FX, aligned dates, LEI ≠ settlement account, verified codes) · REQ-001 · SEC-14 (data-source identity: hashes + provenance) · RSK-15 (unverified codes) · U13 · B4 B7 B8.

**Branch:** `kunal/KG-02-refdata`, stacked on #54 (KG-03, which adds `sl_factory`).

## Decisions (P1, recorded here; flag in PR)
| # | question | decision |
|---|---|---|
| R1 | FX window | 2026-01-02 → 2026-11-19 (last published day at retrieval). ECB pairs USD/GBP/CHF/JPY per EUR; H.10 USD per EUR/GBP, CHF/JPY per USD. KG-04 must keep scenario `as_of` inside the window (factory today draws up to Dec 2026). |
| R2 | H.10 vs ECB | stored as published, never cross-filled; an aligned-date index lists dates both published, so a comparison never uses one source's holiday. |
| R3 | GLEIF subset | 100 ISSUED LEIs per country US, GB, DE, CH, JP (`sort=lei`, page 1) = 500, fields trimmed to lei, legal name, country, category, registration status/last update. No BIC mapping fetched (coverage gap recorded). |
| R4 | ISO 20022 codes | a small curated file (settlement status values used by the bundle + pending/failing reason codes LACK, MONY, CLAC, CMON, CYCL) with meaning + citation, every row `verify: true` until SH-13. Not fetched: the ISO external code set is a spreadsheet download with its own terms. |
| R5 | Network | fetching is a human-run `make refdata-fetch` (generic User-Agent, no credentials); CI and tests never hit the network, they re-hash committed files (`make refdata-verify`). |

## Files
```text
scripts/refdata.py                     stdlib: fetch {ecb,h10,gleif} --date, iso (curated), verify, datasheet
data/reference/<source>/<date>/        raw download + normalized CSV/JSON, committed
data/reference/MANIFEST.json           per snapshot: ref, source, url(s), retrieved_at, license (+ url), files[{path, sha256, rows}], coverage_gaps, caveats, verify
data/reference/DATASHEET_INPUTS.md     generated from MANIFEST for KG-22
packages/scenario-factory/src/sl_factory/refdata.py   the only reader: snapshot(ref) → verified rows; refuses unlisted or tampered files
tests/kit/test_kg_02_refdata.py        parsers on fixture text, manifest/verify, tamper detection (stdlib)
packages/scenario-factory/tests/test_kg_02_loader.py  loader via MANIFEST only; no other sl_factory module opens data/reference
Makefile: refdata-verify (real), refdata-fetch
```

## Steps (each: failing test → code → green)
- [x] 1. Parsers on fixture text: ECB csvdata → (date, base EUR, quote, rate as decimal string); H.10 seriescolumn CSV → (date, pair, rate), `ND` rows dropped and counted; GLEIF JSON → trimmed records. Decimal strings only.
- [x] 2. Snapshot writer: raw + normalized files, sha256 per file, row counts, MANIFEST entry merged by `ref` (idempotent).
- [x] 3. `verify` (**done 1**): `test_KG_02_verify_rehashes_every_snapshot` — every MANIFEST file re-hashes; a tampered byte or a file missing from MANIFEST fails.
- [x] 4. Factory loader (**done 2**): `test_KG_02_factory_reads_refdata_only_via_manifest` — `sl_factory.refdata.snapshot(ref)` returns rows after verifying the hash; unlisted/tampered → error; AST scan: no other `sl_factory` module mentions `data/reference`.
- [x] 5. Datasheet inputs (**done 3**): `test_KG_02_datasheet_inputs_recorded` — DATASHEET_INPUTS.md lists every MANIFEST ref with license, retrieval time, coverage gaps and caveats, and matches a fresh render.
- [x] 6. Fetch the real snapshots (network, once), commit them, `make refdata-verify` green.

## As built
- Fed DDP returns an empty body for `from`/`to` ranges, so the fetch takes `lastobs=260` and cuts to the window; H.10 lags (last observation 2026-11-13 at retrieval), recorded as a coverage gap.
- GLEIF `SOLE_PROPRIETOR` records are excluded (a natural person's name is personal data, golden rule 2): 499 LEIs, exclusion count in MANIFEST.
- FX windows: ECB 2026-01-02..2026-11-19, H.10 ..2026-11-13; 215 aligned dates. **KG-04 must keep scenario `as_of` inside the aligned window.**
