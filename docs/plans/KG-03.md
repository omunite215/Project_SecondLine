# KG-03 Causal break factory core (world, lifecycle, B1–B3) — Implementation Plan

> **For agentic workers:** use superpowers:executing-plans; steps are checkboxes, test first.

**Goal:** `sl_factory` builds a seeded synthetic world, simulates the trade lifecycle as causal events **first**, injects B1–B3 causes into those events, then renders the agent-visible WorldBundle, the privileged Truth and the scenario manifest, all valid against `packages/contracts` and byte-identical for the same seed.

**Spec:** card KG-03 · §5 (lifecycle, entities, ground truth) · §6 · ADR-006 (independent truth) · ADR-016 + docs/domain.md (accounts, precision, B1–B3 deltas, B3 tolerance) · ADR-017 (evidence kinds, agent-must-cite per break) · ADR-015 (opaque ids, truth isolation) · REQ-001 · T-DOM-02 · F10.

**Branch:** `kunal/KG-03-factory-core`, stacked on #14 (KG-01). PR base `main`, title says "stacked on #14".

## Decisions to confirm before building
| # | gap | proposal |
|---|---|---|
| D1 | The card wants an oracle *explanation* in Truth, but `truth.schema.json` has no such field and is `additionalProperties: false`. | KG-03 writes it to a privileged sidecar `truth/explanations/<scenario_id>.json` (inside truth/, same isolation; it also carries the causal event log). A small contract PR (optional `explanation` on `break_truth`, minor bump, `/handoff`, both approve) moves it into Truth after Om's #37 lands. No contract change in this PR. |
| D2 | Truth for the B2 "partial settlement masquerading as booking error" variant. | `break_type` B2_QUANTITY_MISMATCH (symptom-level family), `root_cause` PARTIAL_SETTLEMENT; allowed: CLASSIFY/PARTIAL_SETTLEMENT, ESCALATE/PARTIAL_SETTLEMENT; forbidden: BOOKING_CORRECTION/QUANTITY_MISMATCH; empty delta. |
| D3 | Synthetic identifiers before KG-02 reference data. | ISINs use the ISO user-assigned prefix `QZ` + valid check digit (can't collide with a real ISIN); counterparties are generated names with no LEI/BIC until KG-02; `reference_snapshots` is `[]` for B1–B3 (no FX needed). |
| D4 | B1 timing mechanism. | The custodian statement is cut at its local business-day cutoff (Asia/Tokyo, Europe/London, America/New_York); a settlement whose UTC time falls after that cutoff appears on the next statement, so today's statement lacks it. Hard variant: settlement on a custodian holiday, the same as-of trap. |
| D5 | Seeds. | `scenario seed = derive(split, index)` via SHA-256 of `"{split}:{index}:{GENERATOR_VERSION}"`; no wall clock anywhere. Split seed policy (fingerprints, blind isolation) stays KG-04. KG-03 only ever runs `SPLIT=dev`. |

## As built (deviations from the plan)
- B3 cause is the booking system rounding the 8-dp executed price to 4 dp **HALF_EVEN** (not truncation): truncation only ever under-books, so a break strictly inside tolerance (mixed signs) would be impossible. `within_tolerance` = (+1, +1, −1) minor units over 3 trades.
- KG-03 trades are buys only (sell-side average-cost relief and 4300 arrive with KG-04 hard variants).
- A clean world is not a valid WorldBundle (the contract requires ≥1 break), so the clean-lifecycle test checks balance and an empty recon, not the schema.
- The CLI refuses `eval`/`blind` until KG-04 (split fingerprints, sealed seeds).
